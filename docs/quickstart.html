Quickstart

1. Prerequisites

Required: zsh, git, curl. Everything else is optional and degrades gracefully when missing: starship, antidote, fnm, tmux/zellij/wezterm, and any of the agent CLIs (claude, muse, codex, opencode, pi). The installer does not install these for you (roadmap); install the ones you want first.

2. Install

curl -fsSL https://nitishagar.github.io/polish/install.sh | bash
exec zsh
polish doctor

From a clone instead:

./installer/install.sh --shell zsh
exec zsh
polish doctor

The installer copies the repo to ~/.local/share/polish, symlinks polish and polish-tokens-collect into ~/.local/bin, and appends a marked hook block to your rc file (backing it up to ~/.zshrc.polish-bak). See Self-host for --from, --prefix, --share, and offline options.

3. Verify

polish doctor     # prerequisites, agent CLIs, token cache
polish agents     # agent CLI status table with versions
polish theme      # starship version + config path status

4. Finish the prompt

The installer already deploys the Starship preset to ~/.config/starship.toml (backing up any existing config to starship.toml.polish-bak; symlinked configs are left alone). Only the tmux keybinds stay manual:

# tmux keybinds (prefix-free Alt-hjkl); or source it per-server
ln -sf ~/.local/share/polish/mux/tmux.conf ~/.tmux.conf

Then start the token poller (see Tokens) and pick a multiplexer setup (see Windows).
