Uninstall

~/.local/share/polish/installer/install.sh --uninstall
# or, without the checkout (same flags as install):
curl -fsSL https://nitishagar.github.io/polish/install.sh | bash -s -- --uninstall

With a custom location, pass the same flags you installed with:

./installer/install.sh --uninstall --shell zsh --share ~/.local/share/polish

What it removes

  • The share dir (~/.local/share/polish by default)
  • The polish and polish-tokens-collect symlinks in ~/.local/bin (by default)
  • The marked hook block in your rc file — restored from ~/.zshrc.polish-bak (or ~/.bashrc.polish-bak) when the backup exists, else stripped in place (only when both markers are present; a partial block is left untouched with a warning)
  • The systemd user timer units (polish-tokens.service / polish-tokens.timer), disabled first when user systemd is reachable
  • Your pre-install starship.toml, restored from starship.toml.polish-bak when the backup exists; a config the installer created from nothing is removed again only if still byte-identical, otherwise left for you

It is a clean no-op on an empty home: removing nothing it did not create.

What it leaves (manual cleanup)

  • Token cache: ~/.usage/polish/ — delete it if you want history gone
  • Manual symlinks you created (~/.tmux.conf) and any edited ~/.config/starship.toml — restore or remove them yourself
  • Agent CLIs, starship, antidote, fnm, tmux — never touched (the installer does not manage them)
  • Your rc backup (*.polish-bak) — kept for safety; delete when sure
