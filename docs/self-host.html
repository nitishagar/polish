Self-host

Run Polish from your own clone, fork, or mirror. All paths below are the installer's real flags (see installer/install.sh --help).

Install from a directory

git clone https://github.com/nitishagar/polish ~/src/polish
~/src/polish/installer/install.sh --shell zsh --from ~/src/polish

Running ./installer/install.sh from inside a checkout uses the current directory automatically. --from also accepts a tarball URL, which is downloaded and must contain init.zsh within two levels:

./installer/install.sh --from https://example.com/polish.tar.gz

Install from a fork or pinned version

GITHUB_REPO=myorg/polish POLISH_VERSION=v0.2.0 ./installer/install.sh

Defaults: GITHUB_REPO=nitishagar/polish, POLISH_VERSION=main. Tagged releases also attach a tarball asset (see the release workflow); point --from at its URL to install a pinned release without git.

Custom locations

./installer/install.sh --prefix ~/.local/bin --share ~/.local/share/polish
./installer/install.sh --shell bash   # bash hook (PATH export) instead of zsh
./installer/install.sh --timer        # also install+enable the token-poller timer

The shell defaults to zsh when $SHELL contains zsh, else bash. The zsh hook exports POLISH_DIR and sources $POLISH_DIR/init.zsh; the bash hook exports POLISH_DIR and prepends $POLISH_DIR/bin to PATH. The hook block is marked with # >>> polish >>> / # <<< polish <<< in ~/.zshrc or ~/.bashrc; installation is skipped if the block already exists.

Running from the checkout

You can also skip the installer: put the checkout's bin/ on PATH and point POLISH_DIR at the checkout (polish theme resolves its preset from there). Override or extend without forking via $POLISH_CUSTOM (default ~/.polish-custom): per-plugin overrides in $POLISH_CUSTOM/plugins/<name>/ win over shipped plugins, and $POLISH_CUSTOM/*.zsh is sourced after them. Antidote bundles come from the checkout's .zsh_plugins.txt (git, extract, tmux from OMZ plus deferred autosuggestions and syntax-highlighting).
