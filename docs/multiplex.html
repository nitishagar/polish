Windows

Shell-side helpers live in the polish-mux plugin (autostart + aliases + pickers); real pane switching lives in native tmux/zellij/wezterm keybinds on Alt-hjkl.

Status

polish mux          # same as: polish mux status
polish mux status   # MUX / VERSION / STATUS table + "current: ..."
polish mux detect   # tmux | zellij | wezterm | none for this shell

Detection reads $TMUX, $ZELLIJ, and $WEZTERM_PANE/$WEZTERM_EXECUTABLE. Unknown options error with usage.

tmux config

Polish ships mux/tmux.conf. The installer does not deploy it (it never writes your tmux setup unasked), so link it yourself:

ln -sf ~/.local/share/polish/mux/tmux.conf ~/.tmux.conf
# or per-server: tmux source-file ~/.local/share/polish/mux/tmux.conf

Keybinds (pane switching is prefix-free):

Alt-h/j/k/l        select pane left/down/up/right (no prefix)
Alt-Shift-H/J/K/L  resize active pane 5 cells (no prefix)
Alt-o              cycle to next pane (no prefix)
prefix + | / -     split window horizontally / vertically
prefix + s         session tree picker (choose-tree)
prefix + r         reload ~/.tmux.conf (or a hint when sourced per-server)

tmux keeps sessions across shell exits but not reboots; for reboot-proof sessions use TPM + resurrect/continuum (commented recipe in the file). Some terminals send different escape codes for Alt-Shift combos — verify with cat -v if one fails to fire.

Aliases and pickers

ta  tl  tn <name>   # tmux attach-or-new / list / new named session
za  zl  zn <name>   # zellij attach-or-new / list / named session
wl  wa <domain>    # wezterm cli list / connect (needs a mux server)
pw [name]            # tmux: new window "name" (default "agent"), or select it
mp [tmux|zellij]     # mux_pick session picker (fzf, else numbered list)

mp switches the client when inside tmux, attaches when outside, and never nests zellij. pw errors outside tmux. Set POLISH_TMUX_AUTOSTART=1 to attach (or start) tmux on shell login. zellij uses its defaults (confirm with zellij setup --dump-config); wezterm needs your own wezterm.lua mapping Alt-hjkl to ActivatePaneDirection — Polish ships no wezterm config yet (roadmap).
