Agents

Polish integrates five agent CLIs: claude, muse, codex, opencode, and pi. Missing CLIs are always a quiet hint, never a command not found error.

Status

polish agents         # same as: polish agents status
polish agents status  # AGENT / VERSION / LOCATION table

codex shows gated (not installed) when absent; the others show not installed. Versions are each CLI's first --version line, or (unknown version).

Prompt integration

polish agents --prompt        # one token when a session matches $PWD, else silent
polish agents --prompt-quiet  # exit 0 iff --prompt would emit (no output)

First match wins, in this order: claude, muse, opencode, pi, codex. Detection is read-only: ~/.claude/projects/<pwd>/*.jsonl, recent session.jsonl files with "cwd":"$PWD" under ~/.local/share/muse/sessions, a read-only query of the opencode session/project tables, ~/.pi/agent/sessions/--<pwd>--/*.jsonl (session files only — auth.json is never read), and ~/.codex/sessions lines matching a cwd-like field ("cwd"|"directory"|"workdir"|"workspace"|"root":"$PWD" — incidental path mentions never match). Codex is gated: it is consulted only when the codex CLI is installed. The Starship preset runs one polish agents --prompt per render for the polish_agent module (empty output hides it).

Session helpers (polish-ai plugin)

polish_agents        # one line per CLI: path or "not installed"
claude_continue      # claude --continue
claude_resume [id]   # claude --resume [id]
muse_continue        # muse resume --last
muse_resume [ref]    # muse resume [ref] (picker when bare)
opencode_continue    # opencode run --continue
opencode_resume <id> [msg...]  # opencode run --session (id required)
pi_continue          # pi --continue
pi_resume [id]       # pi --session [id], or pi --resume picker when bare

Aliases

pcl  pcr   # claude_continue / claude_resume
pml  pmr   # muse_continue / muse_resume
poc  por   # opencode_continue / opencode_resume
ppi  ppr   # pi_continue / pi_resume

Every helper funnels through a guard that prints <cli>: not installed and returns 1 when the CLI is missing, so the aliases are safe to invoke anywhere. Per-agent Codex launchers are roadmap (Codex paths stay gated until the CLI exists).
